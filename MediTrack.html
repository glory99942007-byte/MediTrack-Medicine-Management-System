About MediTrack

MediTrack is a frontend medicine inventory management project developed using HTML, CSS and JavaScript.


Features:


  • Add, edit and delete medicine records
  • Search and filter medicines
  • Monitor low stock items
  • Identify expired and soon-to-expire medicines
  • Update stock quantities
  • Export inventory as CSV
  • Save records in browser LocalStorage
